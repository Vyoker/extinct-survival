Kebijakan Privasi — Extinct Survival

Terakhir diperbarui: 21 November 2026 · Pengembang: VyokerDEV

Extinct Survival adalah game survival RPG yang dikembangkan oleh VyokerDEV. Kebijakan ini menjelaskan data apa yang kami kumpulkan, mengapa, dan bagaimana data tersebut dilindungi saat Anda memainkan Extinct Survival versi aplikasi Android (Google Play).

1. Data yang tersimpan di perangkat Anda

Progres permainan (level, inventaris, misi, pengaturan) disimpan secara lokal di perangkat Anda. Data ini tidak dikirim ke mana pun kecuali Anda secara sadar memakai fitur Simpan Online di bawah ini.

2. Simpan Online / Cloud Save (opsional)

Jika Anda memakai fitur Simpan Online, data permainan Anda — termasuk nama pemain yang Anda pilih — diunggah ke layanan penyimpanan cloud kami agar bisa dimuat di perangkat lain. Data ini hanya bisa diakses memakai kode rahasia 16 karakter yang Anda buat sendiri; tanpa kode tersebut, tidak ada yang bisa membuka data simpanan Anda, termasuk kami. Ukuran data dibatasi maksimal 512 KB per simpanan.

3. Chat dan kehadiran pemain (opsional)

Jika Anda memakai chat global di dalam game, nama pemain dan pesan chat yang Anda kirim akan terlihat oleh pemain lain yang sedang online. Pesan dibatasi maksimal 200 karakter, dengan jeda 15 detik antar pesan, dan tautan tidak diizinkan. Kami tidak memakai chat untuk mengumpulkan data pribadi Anda.

4. Pembelian dalam aplikasi via Google Play

Pembelian kredit di aplikasi ini diproses sepenuhnya oleh Google Play. Paket kredit yang tersedia adalah 100, 250, 600, dan 1.500 Kredit. Saat Anda membeli paket kredit, kami mencatat: ID produk, ID order Google, dan token pembelian untuk keperluan verifikasi agar kredit masuk ke akun permainan Anda dan tidak terjadi pemberian ganda. Pembayaran dilakukan di layar Google Play — kami tidak pernah menerima, melihat, atau menyimpan nomor kartu, PIN, atau kredensial bank Anda. Tidak ada metode pembayaran lain di dalam aplikasi ini. Data pembayaran Anda tunduk pada Kebijakan Privasi Google.

5. Iklan

Aplikasi ini menampilkan iklan reward dari Google AdMob. Menonton 1 iklan reward memberikan 1 Kredit. Iklan hanya ditampilkan jika Anda memilih untuk menontonnya. AdMob dapat mengumpulkan ID iklan perangkat dan informasi perangkat untuk menampilkan iklan, sesuai dengan Kebijakan Privasi Google. Anda dapat mengatur ulang atau menonaktifkan personalisasi iklan melalui pengaturan perangkat Android Anda.

6. Data yang TIDAK kami kumpulkan

  • Lokasi perangkat, kontak, foto, atau mikrofon.
  • Data kartu, rekening, atau kredensial pembayaran apa pun.

7. Berbagi data

Kami tidak menjual data Anda. Data diproses hanya oleh layanan yang menjalankan aplikasi ini:

  • Google Play — pemroses pembayaran pembelian dalam aplikasi.
  • Google AdMob — penyedia iklan reward.
  • Google Firebase — layanan chat dan kehadiran pemain.
  • Netlify — hosting permainan dan penyimpanan cloud save serta verifikasi pembelian.

8. Keamanan

Seluruh komunikasi antara aplikasi dan server kami memakai koneksi terenkripsi (HTTPS). Akses administratif ke data order dan cloud save dibatasi dan dicatat.

9. Hak Anda

Anda dapat meminta penghapusan data cloud save atau catatan pembelian Anda kapan pun dengan menghubungi kami (lihat Kontak di bawah) disertai kode rahasia cloud save atau kode order Anda. Menghapus aplikasi akan menghapus data lokal di perangkat, tetapi tidak menghapus cloud save yang pernah diunggah — gunakan permintaan penghapusan untuk itu.

10. Anak-anak

Extinct Survival ditujukan untuk pengguna berusia 13 tahun ke atas. Kami tidak secara sadar mengumpulkan data dari anak di bawah 13 tahun.

11. Perubahan kebijakan

Jika kebijakan ini berubah, tanggal "Terakhir diperbarui" di atas akan disesuaikan. Perubahan material akan diumumkan di dalam permainan.
