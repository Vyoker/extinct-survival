Kebijakan Privasi — Extinct Survival

Terakhir diperbarui: 22 Oktober 2026 · Pengembang: VyokerDEV

Extinct Survival adalah game survival RPG yang dikembangkan oleh VyokerDEV. Kebijakan ini menjelaskan data apa yang kami kumpulkan, mengapa, dan bagaimana data tersebut dilindungi saat Anda memainkan Extinct Survival versi web maupun versi aplikasi Android (Google Play).

1. Data yang tersimpan di perangkat Anda

Progres permainan (level, inventaris, misi, pengaturan) disimpan secara lokal di perangkat Anda. Data ini tidak dikirim ke mana pun kecuali Anda secara sadar memakai fitur Simpan Online di bawah ini.

2. Simpan Online / Cloud Save (opsional)

Jika Anda memakai fitur Simpan Online, data permainan Anda — termasuk nama pemain yang Anda pilih — diunggah ke layanan penyimpanan cloud kami agar bisa dimuat di perangkat lain. Data ini hanya bisa diakses memakai kode rahasia 16 karakter yang Anda buat sendiri; tanpa kode tersebut, tidak ada yang bisa membuka data simpanan Anda, termasuk kami. Ukuran data dibatasi maksimal 512 KB per simpanan.

3. Top Up via QRIS (versi web / APK non-Play Store)

Saat Anda membuat order top up, kami mencatat: kode order, ID dan nama pemain, paket yang dipilih, nominal pembayaran, dan status order. Pembayaran dilakukan di aplikasi e-wallet / m-banking milik Anda sendiri — kami tidak pernah menerima, melihat, atau menyimpan nomor kartu, PIN, atau kredensial bank Anda. Order yang tidak dibayar kedaluwarsa otomatis dalam 30 menit.

4. Pembelian dalam aplikasi via Google Play (versi Play Store)

Pembelian kredit pada versi Play Store diproses sepenuhnya oleh Google Play. Kami hanya menerima ID produk, ID order Google, dan token pembelian untuk keperluan verifikasi agar kredit masuk ke akun permainan Anda dan tidak terjadi pemberian ganda. Data pembayaran Anda tunduk pada Kebijakan Privasi Google.

5. Iklan

Versi Play Store tidak menampilkan iklan dan tidak memakai SDK periklanan apa pun. Izin aplikasi versi Play Store hanya INTERNET, yang dipakai untuk memuat permainan dan memverifikasi pembelian.

6. Data yang TIDAK kami kumpulkan

  • Lokasi perangkat, kontak, foto, atau mikrofon.
  • ID iklan perangkat (tidak ada SDK iklan di versi Play Store).
  • Data kartu, rekening, atau kredensial pembayaran apa pun.

7. Berbagi data

Kami tidak menjual data Anda. Data diproses hanya oleh layanan yang menjalankan aplikasi ini:

  • Google Play — pemroses pembayaran pembelian dalam aplikasi.
  • Netlify — hosting permainan dan penyimpanan cloud save serta catatan order.

8. Keamanan

Seluruh komunikasi antara aplikasi dan server kami memakai koneksi terenkripsi (HTTPS). Akses administratif ke data order dan cloud save dibatasi dan dicatat.

9. Hak Anda

Anda dapat meminta penghapusan data cloud save atau catatan order top up Anda kapan pun dengan menghubungi kami (lihat Kontak di bawah) disertai kode rahasia cloud save atau kode order Anda. Menghapus aplikasi akan menghapus data lokal di perangkat, tetapi tidak menghapus cloud save yang pernah diunggah — gunakan permintaan penghapusan untuk itu.

10. Anak-anak

Extinct Survival ditujukan untuk pengguna berusia 13 tahun ke atas. Kami tidak secara sadar mengumpulkan data dari anak di bawah 13 tahun.

11. Perubahan kebijakan

Jika kebijakan ini berubah, tanggal "Terakhir diperbarui" di atas akan disesuaikan. Perubahan material akan diumumkan di dalam permainan.
